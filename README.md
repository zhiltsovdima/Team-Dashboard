# Team-Dashboard
## О проекте

**TeamDashboard** — тестовое мобильное приложение, созданное для экспериментов с архитектурой **[The Composable Architecture (TCA)](https://github.com/pointfreeco/swift-composable-architecture)**. Основная цель проекта — исследовать возможности TCA, научиться использовать навигацию, зависимости и другие основные фишки этой архитектуры.

На данный момент проект находится в активной разработке
## Почему TCA?
Классические архитектуры вроде MVVM как будто не совсем в духе философии SwiftUI. TCA — это свежий взгляд, который переосмысливает привычные подходы. Меня зацепила её строгость, четкий контроль над данными и очень приятное тестирование.
## Технологии
SwiftUI, TCA
